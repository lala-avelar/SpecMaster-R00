## 1. Correção de crash inicial

- **Bug:** o dev server do Vite respondia `/api/*` com o `index.html` (200/text-html). O fallback `projectsQuery.data?.length` tratava a string como array → `projects.find(...)` quebrava e caía no ErrorBoundary.
- **Fix:** guardas com `Array.isArray` + type guard `isProjectDetail()`.

## 2. Refatoração da Matriz de Especificações (núcleo do MVP)

- **Painel de saúde orçamentária** por zona: Custo Previsto / Total Cotado / Estouro·Saldo (convenção: estouro = `−`, saldo = `+`, depois de correção).
- **Coluna Δ** por linha (R$), **preço cotado em vermelho** quando estoura a verba.
- Filtro **"Ver apenas estouros"**, pill "Revisão Pendente", rastro de alterações ("O que mudou").
- Removido: coluna "Rev.", **Board View** e scroll horizontal.
